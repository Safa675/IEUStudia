# Security

IEUStudia keeps your IEULearn (EkoID) password encrypted with Windows DPAPI on your own PC and sends it only to
`learn.ieu.edu.tr`. There is no IEUStudia server.

## Reporting a vulnerability

Please don't open a public issue. Use GitHub's private vulnerability reporting instead (*Security → Report a
vulnerability* on the repository page) and include:

- what is affected and how it could be exploited,
- steps to reproduce it, without real passwords or personal data,
- the IEUStudia version (*Settings → About*).

You'll get an answer as soon as possible, and fixes are released as a new version.
